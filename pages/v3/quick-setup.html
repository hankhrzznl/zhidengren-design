自动记账

iOS 不允许 App 后台读微信 / 支付宝账单，所以做法是：用快捷指令把「金额」拼成一条记账链接，打开就记好。下面按覆盖面从高到低排。

1
分享 / 复制账单（微信、支付宝）复制账单文本 → 点一下「记一笔」快捷指令。覆盖最广，需要一次配置。
2
银行短信自动（真自动）收到含「消费」的短信 → 自动解析金额 → 打开链接。
3
Apple Pay 自动（iOS 17+）「交易」自动化，只覆盖 Apple Pay，需实测。
4
Siri / 背面轻点（最快手动）「嘿 Siri，记一笔」或双击手机背面。
生成你的记账链接
https://my-lifeos.com/app/v3/expense.html?quick=[金额]&cat=餐饮&account=微信钱包

快捷指令里把 [金额] 换成「数字」变量即可；account 也可以删掉，默认用第一个资产账户。

快捷指令怎么建
  1. 打开「快捷指令」→ 右上角 ＋ → 命名「记一笔」；
  2. 点详情 → 打开 在共享表单中显示，接收类型选 文本；
  3. 加动作 「从输入中获取数字」（或「匹配文本」正则 (?:¥|￥)\s*([0-9]+(?:\.[0-9]{1,2})?)）；
  4. 加动作 「打开 URL」，粘贴上面复制的模板，把 [金额] 换成第 3 步的数字变量；
  5. 保存。之后在微信/支付宝账单里复制文本 → 分享 → 选「记一笔」。

短信自动化：快捷指令 → 自动化 → 信息 → 包含「消费」→ 立即运行 → 同样的「打开 URL」。

云收件箱（可选 · 需要 Supabase 项目）

配好后，快捷指令用「获取 URL 内容」直接 POST，不用打开 Safari；记账页打开时自动拉取。数据只存在你自己的 Supabase 项目里。

每月对账提醒

每月固定一天，导出支付宝/微信账单 CSV 并导入，补齐零钱消费。日子你自己定。

去导入
  1. 支付宝：我的 → 账单 → 右上角「…」→ 开具交易流水证明 / 导出账单 → 选时间段 → 填邮箱 → 邮件里解压出 CSV。
  2. 微信：我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单 → 用于个人对账 → 选时间段 → 填邮箱 → 解压出 CSV。
  3. 导入：导入账单 → 选 CSV → 看预览 → 导入（按日期+金额+商户去重）。
  4. 提醒：点「添加到日历」下载 .ics，用 iPhone 日历打开，会每月重复并在当天提醒；或让 Siri 每月这天提醒你。
微信 / 支付宝零钱

零钱付款没有银行短信，两条路：

① 付款后截图 → 分享给「记一笔」快捷指令（快捷指令里加「从图像提取文本」）；

② 每月导出账单 CSV，一次性补全：导入账单 CSV →

现金 / 临时

用 Siri「记一笔」或背面轻点，输入金额即可；也可以直接打开记账页手动记。

不想配快捷指令？

回到记账页，用「粘贴账单」：复制微信/支付宝账单后点一下，金额、商户、分类会自动填好，确认「记下」即可。
