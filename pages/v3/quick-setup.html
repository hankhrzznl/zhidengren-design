自动记账

你的方案：每月 1 号，导出支付宝 + 微信账单 CSV，导入一次；平时现金/临时手动记。不需要银行短信、Apple Pay、Supabase 或快捷指令。

去导入
  1. 支付宝：我的 → 账单 → 右上角「…」→ 开具交易流水证明 / 导出账单 → 选整月 → 填邮箱 → 邮件里解压出 CSV。
  2. 微信：我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单 → 用于个人对账 → 选整月 → 填邮箱 → 解压出 CSV。
  3. 导入：导入账单 → 选 CSV → 看预览 → 导入（按日期+金额+商户去重）。
  4. 完成：点「本月已完成」，下个月自动重新提醒。
导入时会自动跳过

转账 / 充值 / 提现 / 还款 默认跳过，避免把「账户之间挪钱」记成消费；导入页可以手动关掉这个开关。

现金 / 临时

直接打开记账页手动记；复制了账单文本的话，点金额框右边的「粘贴账单」自动填。

Supabase 云收件箱与 iOS 快捷指令已停用，不需要配置；代码保留但不再使用。
