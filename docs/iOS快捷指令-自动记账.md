# iOS 快捷指令 · 自动记账方案

> 目标：把「微信 / 支付宝 / 银行卡 / Apple Pay」的消费，尽量少操作地记进 `my-lifeos.com/app` 的账本。
> 结论先说：**iOS 不允许第三方 App 在后台读取微信/支付宝账单**，所以不存在「全自动、零操作」的官方方案；
> 最科学的是「**统一 URL 记账协议 + 分渠道触发器**」：能全自动的（短信、Apple Pay）全自动，不能的用分享/轻点/Siri 做到一两步。

---

## 一、能力边界（先认清，避免白折腾）

| 渠道 | 可否自动触发 | 可行方式 |
|---|---|---|
| 银行刷卡短信 | ✅ 可全自动 | 快捷指令「信息」自动化：收到含「消费」的短信 → 解析金额 → 打开记账 URL |
| Apple Pay | ✅ 可自动（iOS 17+） | 快捷指令「交易 / 钱包」自动化 |
| 银行邮件账单 | ⚠️ 部分可 | 「邮件」自动化（需邮箱已加到 iPhone） |
| 微信支付 | ❌ 不能后台自动 | 付款后分享账单/复制文本 → 分享扩展；或 Siri/背面轻点 |
| 支付宝 | ❌ 不能后台自动 | 同上 |
| 云闪付/美团等 | ❌ | 同上（有分享文本就行） |

原因：微信/支付宝没有向 Shortcuts 暴露「支付完成」事件，iOS 也不允许读其他 App 的数据。任何声称「全自动读微信账单」的方案，要么要越狱，要么要抓包/无障碍，都不稳定也不安全。

---

## 二、App 侧已实现的「URL 记账协议」

记账页支持用 URL 直接记一笔，供快捷指令调用：

```
https://my-lifeos.com/app/v3/expense.html?quick=38&cat=餐饮&note=午饭&account=微信钱包
```

参数：

| 参数 | 必填 | 说明 |
|---|---|---|
| `quick` 或 `amount` | 是 | 金额，正数；`38` / `38.5` |
| `type` | 否 | `expense`（默认）/ `income` |
| `cat` | 否 | 分类：餐饮/交通/购物/日常/房租/还款… 默认「日常」 |
| `note` | 否 | 备注，建议放商家名 |
| `account` | 否 | 账户名或 id；不填默认第一个资产账户 |
| `date` | 否 | `2026-10-19` 或 `2026-10-19`，默认今天 |

行为：

- 打开页面即写入一笔，顶部弹出「已记 ¥38 · 微信钱包 · 餐饮」，**9 秒内可点「撤销」**；
- URL 参数会自动清理，不会留在地址栏；
- 同时写一条「记账」事实，四账户的 **志** 和灯照常计算。

> 安全：任何网页都能构造这个链接，但它只能写你本机的 localStorage，不会上传；不放心可以只在需要时用，或以后加一个本地口令参数。

**先手动验证**：用 Safari 打开上面那条链接，看到「已记 ¥38」就说明协议通了。

## 三、方案 A：分享扩展（覆盖微信 / 支付宝，最通用）

适合：微信/支付宝账单详情能「复制」或「分享」出文本时。

### 快捷指令步骤

1. 新建快捷指令，命名「记一笔」；
2. 打开「在共享表单中显示」，接收类型选 **文本**（和 URL）；
3. 加动作 **「从输入中获取数字」**（Get Numbers from Input）——或更稳的 **「匹配文本」**：
   - 正则：`(?:¥|￥|金额[:：]?\s*)([0-9]+(?:\.[0-9]{1,2})?)`
   - 取第 1 个捕获组；
4. 加动作 **「打开 URL」**：
   ```
   https://my-lifeos.com/app/v3/expense.html?quick=【数字】&cat=餐饮&note=【输入文本】
   ```
   - 备注里放整段文本会太长，建议再取一次「商家」：正则 `(?:商户|收款方)[:：]?\s*([^\n]+)`；
5. （可选）加「显示通知」：已记账。

### 用法

- 微信：我 → 服务 → 钱包 → 账单 → 点开某笔 → 右上角「…」→ 复制/分享 → 选「记一笔」；
- 支付宝：账单 → 点开 → 分享/复制 → 「记一笔」；
- 也可以把「记一笔」放到**锁屏小组件**或**主屏图标**，先复制账单文本，再点一下。

## 四、方案 B：短信自动化（覆盖银行卡，真·自动）

适合：银行每笔消费都发短信。

1. 新建快捷指令「短信记账」：
   - 接收「快捷指令输入」里的短信文本；
   - 「匹配文本」正则：`(?:消费|支出|扣款)[^0-9]{0,6}([0-9]+(?:\.[0-9]{1,2})?)`；
   - 「打开 URL」：`…?quick=【金额】&cat=日常&note=银行短信&account=招商银行卡`；
2. 快捷指令 App → **自动化** → 新建 → **信息**：
   - 「信息包含」填 `消费`（或你的银行短信号码）；
   - 选择「立即运行」（不要选「运行前询问」）；
   - 关闭「运行前询问」后，iOS 可能仍会弹通知，属正常。

注意：不同银行短信格式不同，正则要按你的短信改；先拿一条真实短信在「匹配文本」里试。

---

## 五、方案 C：Apple Pay 交易自动化

iOS 17+ 的「交易」自动化可以在 Apple Pay 刷卡后触发：

1. 自动化 → **交易** → 选择卡/商家（可留空）；
2. 动作：取交易金额 → 「打开 URL」`…?quick=【金额】&cat=购物&note=Apple Pay`；
3. 选「立即运行」。

限制：只覆盖 Apple Pay，不覆盖微信/支付宝；且 Apple 的「交易」自动化在部分系统版本上不稳定（开发者论坛有反馈），需要自己实测。

---

## 六、方案 D：Siri / 背面轻点（最快的手动）

- Siri：「嘿 Siri，记一笔」→ 快捷指令「要求输入」金额和备注 → 打开 URL；
- 背面轻点：设置 → 辅助功能 → 触控 → 轻点背面 → 双击 → 选「记一笔」；
- 锁屏小组件：把「记一笔」放到锁屏，点一下即可。

适合「付完款顺手记」，比打开 App 点半天快。

---

## 七、推荐组合（最科学）

```
微信/支付宝  → 方案 A 分享扩展（复制账单 → 点「记一笔」）
银行卡短信   → 方案 B 短信自动化（全自动）
Apple Pay    → 方案 C 交易自动化（全自动，需实测）
临时/现金    → 方案 D Siri / 背面轻点
```

这样覆盖 90% 的消费，且**不依赖任何第三方记账 App、不上传账单**。

## 八、常见问题

**Q：能不能做到「付完款什么都不用做」？**
微信/支付宝不能；银行卡短信和 Apple Pay 可以（方案 B/C）。这是 iOS 的沙盒限制，不是本项目的实现问题。

**Q：快捷指令打开 Safari 会不会很慢？**
第一次冷启动 1–2 秒；页面有 Service Worker 缓存，之后通常 <1 秒。也可以把记账页「添加到主屏幕」，从主屏打开。

**Q：记错了怎么办？**
弹出条上有「撤销」；超过 9 秒去「流水」里删除，或长按……目前流水删除还没做 UI，可在控制台用 `LightLedger.removeTx(id)`；后续可补。

**Q：多设备同步？**
目前数据在各自浏览器的 localStorage，不跨设备。要跨设备需要后端账户体系，属于另一个量级的改造。

**Q：安全吗？**
URL 只写本机；但如果别人拿你手机打开恶意链接，可能塞一笔假账。可加「localStorage 口令」参数校验，或只在信任的环境使用。
