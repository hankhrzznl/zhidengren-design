# 生命系统 · 全模块整体模型（四账五流）

> 上一版只覆盖了睡眠/训练/饮食/情绪，漏了学习、输出、关系、独处、记账、预算、时间、目标、穿搭、吃药、冥想等。
> 这一版把全部模块放进同一张图：**四账是资本，五流是预算，状态是今日余额，灯是今天把余额花在哪。**

---

## 一、先盘点：现在到底有多少模块

| 域 | 模块 | 主要作用 |
|---|---|---|
| **体能** | 睡眠、饮食、饮水、运动、休息、吃药、功法养生 | 维持生理底座 |
| **情感** | 情绪记录、关系、独处、恢复、冥想 | 调节情绪与连接 |
| **智识** | 学习、思考、输出、成长 | 积累知识与产出 |
| **资源** | 记账、预算、时间、长期目标、穿搭 | 管理金钱、时间、方向 |
| **元层** | 灯、今日状态、日程/任务/习惯、回顾 | 决定今天做什么、每周怎么调 |

这些不是 20 个独立 App，而是**同一套预算的 20 种花法**。

---

## 二、四账：长期资本

沿用现有四域：

- **体**：睡眠、饮食、饮水、运动、休息、吃药、功法；
- **情**：情绪、关系、独处、恢复、冥想；
- **智**：学习、思考、输出、成长；
- **志/资源**：记账、预算、时间、目标、穿搭。

四账是**慢变量**：看周/月，不看一天。一晚没睡好，不该把「体」账户打崩；一次冲动消费，也不该把「志」清零。

---

## 三、五流：每天/每周真正被分配的预算

所有模块都在花这五种东西：

| 流 | 谁在生产 | 谁在消耗 | 透支信号 |
|---|---|---|---|
| **时间** | 睡眠/休息（恢复时间） | 工作、训练、学习、社交、通勤 | 没时间吃饭/训练/复盘 |
| **精力** | 睡眠、饮食、饮水、休息 | 训练、加班、久坐、熬夜 | 白天靠咖啡因、训练掉重量 |
| **注意力** | 睡眠、冥想、独处 | 学习、思考、输出、短视频、多任务 | 看不进书、反复刷手机 |
| **情绪** | 关系、独处、冥想、运动、输出 | 冲突、压力、比较、睡眠不足 | 易怒、麻木、逃避 |
| **金钱** | 工作/输出/预算 | 消费、订阅、穿搭、外卖 | 月底焦虑、用买东西解压 |

**四账是资本，五流是现金流。** 资本可以慢慢攒，现金流每天都会归零。

## 四、状态：今日余额

每天 10 秒，4 个 1–5 分 + 1 个选择：

| 输入 | 对应域 |
|---|---|
| 睡眠 | 体 |
| 酸痛 | 体 |
| 情绪 | 情 |
| 压力 | 情/志 |
| **今天最紧的预算**：时间 / 精力 / 注意力 / 情绪 / 钱 | 决定今天先保哪一块 |

颜色：

- **绿**：按计划；
- **黄**：减 20–30% 负荷，保睡眠；
- **红**：只做恢复，不做重大决定/大额消费/大重量。

> 不做总分。分数会让你问「为什么 72」，颜色会让你问「今天先保什么」。

## 五、模块之间的 6 条耦合通道

不是每两个模块都直接相关，它们通过 6 条通道互相影响：

### 1. 时间通道

- 训练 60′、学习 45′、做饭 30′、通勤 40′ 都在抢同一份 24h；
- 时间贫困 → 先砍睡眠/做饭/训练，最后才砍工作；
- **规则**：一天最多 2 个「大块」——训练、深度学习、社交，三选二。

### 2. 精力通道

- 睡眠/饮食/饮水 → 精力；
- 训练/加班/久坐 → 消耗；
- **规则**：睡眠 <6h，训练组数 −30%，不练爆发；不开长会。

### 3. 注意力通道

- 睡眠/冥想/独处 → 注意力；
- 学习/思考/输出/多任务 → 消耗；
- **规则**：注意力 ≤2，只做 1 个 45 分钟块，不接新任务。

### 4. 情绪通道

- 关系/独处/运动/输出 → 情绪；
- 冲突/比较/睡眠不足/透支 → 消耗；
- **规则**：情绪 ≤2，先 10 分钟走路或联系一个人，不用购物/暴食/高强度训练「修复」。

### 5. 金钱通道

- 工作/输出/预算 → 金钱；
- 消费/订阅/穿搭/外卖 → 消耗；
- **规则**：金钱压力高时，先看预算，不先砍吃饭和睡眠；大额消费延迟 24h。

### 6. 意义通道

- 目标/输出/关系/成长 → 意义感；
- 无意义的工作/刷屏/比较 → 消耗；
- **规则**：意义感低时，先做一件「能完成的小输出」，不是加更多计划。

## 六、正循环与负循环

### 负循环（要提前打断）

```
睡不好 → 训练表现差 → 加练/喝咖啡 → 更睡不好
情绪低 → 冲动消费 → 账单焦虑 → 更睡不好
时间紧 → 不做饭/不训练 → 精力差 → 效率更低 → 时间更紧
学习卡住 → 刷手机 → 注意力更差 → 更卡
```

### 正循环（要设计）

```
睡够 → 训练稳 → 情绪稳 → 少吃情绪性进食 → 睡更好
关系/独处 → 情绪回血 → 工作专注 → 有钱有闲 → 更愿意关系
小输出 → 成就感 → 学习动力 → 更大输出
预算清楚 → 金钱焦虑低 → 睡眠稳 → 工作表现好
```

产品不该「预测」这些循环，而是**在关键节点给一个最小动作**。

## 七、统一架构：四层

```
L4 意义/方向：长期目标、灯、回顾
        ↑
L3 资源/结构：时间、金钱、预算、穿搭
        ↑
L2 认知/产出：学习、思考、输出、成长
        ↑
L1 情绪/关系：情绪、关系、独处、冥想、恢复
        ↑
L0 生理底座：睡眠、饮食、饮水、运动、休息、吃药、功法
```

- 下层不稳，上层做不动；
- 上层给下层意义，不然恢复变成「躺平」；
- 任何一天，只从**最不稳的一层**动手。

## 八、产品落点：一张今日卡 + 四个模块页

### 1. 壳层「今日状态」卡

```
今天：黄
睡 6.2h · 腿酸 3 · 压力 3
最紧：时间
建议：训练减 1 组；学习只做 1 个 45′ 块；不接新任务。
```

- 4 个打分 + 1 个「最紧预算」；
- 只给 1–2 条建议，不给 10 条。

### 2. 每个模块页只读状态，不互相写

| 模块 | 读到状态后 |
|---|---|
| 训练 | 黄：组数 −1、RPE 7；红：只走路 |
| 睡眠 | 明天有训练：今晚目标 7.5h |
| 学习 | 注意力低：只安排 1 个块 |
| 记账 | 情绪低/金钱压力高：大额消费延迟 24h |
| 关系 | 情绪低：提示联系一个人，而不是刷手机 |
| 目标 | 时间紧：本周只推进 1 个目标 |

### 3. 周复盘：看五流，不只看训练

```
本周：
时间：训练 4 次 · 加班 3 天 · 熬夜 2 天
精力：睡眠均值 6.4h · 咖啡 5 杯
注意力：深度学习 3 块 · 输出 1 篇
情绪：记录 4 天 · 联系朋友 1 次
金钱：支出 1,840 · 预算剩 38%
建议：下周只加 1 个休息日，不加训练量。
```

### 4. 数据

```json
state: {
  "date": "2026-10-24",
  "sleep": 3, "soreness": 3, "mood": 4, "stress": 2,
  "tightest": "time",
  "color": "yellow"
}
```

- 独立 `lifeflow-state-v1`；
- 模块只读，不互相写；
- 周复盘从各模块读汇总，不复制数据。

## 九、全模块规则（先做 6 条）

1. **睡眠 <6h 或红**：训练减量、学习只留 1 块、不开长会；
2. **大重量腿日**：当晚睡眠 +30 分钟，训练不晚于 21:30；
3. **情绪 ≤2**：先走路/联系一个人，不购物、不暴食、不冲大重量；
4. **金钱压力高**：先看预算，不砍吃饭/睡眠；大额消费延迟 24h；
5. **时间贫困**：当天最多 2 个大块，先保睡眠和一顿正餐；
6. **注意力 ≤2**：只做 1 个 45 分钟块，不接新任务。

## 十、分阶段

- **P0**：今日状态卡（4 分 + 最紧预算 + 颜色）；
- **P1**：训练/睡眠/学习/记账 4 个页面读状态，各给 1 条建议；
- **P2**：周复盘合并五流；
- **P3**：趋势与相关性（只展示，不宣称因果）。

## 十一、不做什么

- 不做单一「生命分」；
- 不做医学诊断；
- 不自动改计划/自动花钱/自动替用户做决定；
- 不追求 20 个模块全联动，先做 6 条硬规则；
- 不把「记录」变成第二份工作：每天 10 秒，每周 5 分钟。
