# 生命系统 · 保底模型（Floor System）

> 研究结论：**人不是 20 个模块的仪表盘，而是有限容量下的优先级系统。**
> 更好的整体思想不是「把所有模块都优化」，而是：**每个域保一个底，预算不够时先保底，环境不对时改环境，不靠意志力。**

---

## 一、这次真正研究了什么

| 理论 | 核心 | 对产品的启示 |
|---|---|---|
| **Allostasis / 适应负荷**（McEwen） | 身体通过改变来维持稳定；长期高负荷会累积磨损 | 不是「练得越多越好」，恢复是主动过程；看长期负荷，不看单日 |
| **JD-R 工作要求-资源模型** | 高要求 + 低资源 → 耗竭；资源能缓冲要求 | 模块之间不是平级，资源（睡眠/支持/时间）决定你能承受多少要求 |
| **COM-B 行为模型**（Michie） | 行为 = 能力 + 机会 + 动机 | 没做到往往不是「不自律」，是**机会/环境**不对；改环境比加意志力有效 |
| **自我决定论 SDT** | 自主、胜任、连接 | 目标/关系/输出提供持续动机；纯打分外部驱动会反噬 |
| **个人 informatics 阶段模型**（Li 等） | 收集 → 整合 → 反思 → 行动 | 记录不是目的；没有反思与行动，数据会变成负担 |
| **还原性指标批判** | 单一分数会掩盖原因、制造焦虑 | 不做「生命分」；用保底状态代替总分 |
| **时间贫困 / 稀缺** | 时间压力会挤占健康行为 | 先看时间预算，不要用「自律」解释没时间 |

参考：
- [A Stage-Based Model of Personal Informatics Systems](https://dl.acm.org/doi/epdf/10.1145/1753326.1753409)
- [Allostasis and Allostatic Load](https://nyaspubs.onlinelibrary.wiley.com/doi/abs/10.1111/j.1749-6632.1998.tb09546.x)
- [COM-B / 行为改变轮](https://www.tandfonline.com/doi/full/10.1080/1750984X.2021.1904434)
- [还原性追踪指标的批判](https://api.repository.cam.ac.uk/server/api/core/bitstreams/3e6de21e-aa61-4c85-83e5-36b8d1a40f70/content)

## 二、上一版「四账五流」的问题

1. **把五流当成可互换的预算**：时间、精力、注意力、情绪、钱不能相加，也不能互相抵扣。
2. **没有「底」**：每个模块都想优化，最后变成 20 个目标，用户不知道先保哪个。
3. **忽略了机会/环境**：没时间不是动机问题，是日程/通勤/照护结构问题。
4. **仍然是「满分思维」**：默认所有模块都该高分，反而制造焦虑。
5. **模块太多**：20 个模块每天看一遍，记录本身变成第二份工作。

---

## 三、新模型：四域保底 + 五流约束 + 一个方向

```
方向：我这一阶段在乎什么（1 个）
        ↑
五流约束：时间 / 精力 / 注意力 / 情绪 / 钱
        ↑
四域保底：体 / 情 / 智 / 志
```

- **四域保底**：每个域只设 1–3 个「最低有效剂量」，不是满分目标；
- **五流约束**：决定今天能保几个底；
- **一个方向**：决定哪个底优先，哪些模块可以暂停。

### 一句话

**保底，不追满分；先保底，再谈优化；改环境，不加意志力。**

---

## 四、四域保底清单（可配置）

### 体（生理底座）

| 保底 | 最低剂量 | 说明 |
|---|---|---|
| 睡眠 | ≥7h，或 6.5h + 20min 午休 | 最重要，优先于训练 |
| 吃饭 | ≥2 餐，其中 1 餐有蛋白 | 不追求完美饮食 |
| 喝水 | 1.5L | 或 6 杯 |
| 活动 | ≥20min 走路/训练 | 不要求每次 60min |
| 吃药 | 按医嘱 | 医疗项，不作优化 |

### 情（情绪/关系）

| 保底 | 最低剂量 |
|---|---|
| 情绪签到 | 每天 1 次（10 秒） |
| 真实连接 | 每周 1 次（见面/电话，不是点赞） |
| 独处/呼吸 | 每天 10 分钟 |

### 智（认知/产出）

| 保底 | 最低剂量 |
|---|---|
| 专注块 | 每天 1 个 45 分钟 |
| 输出 | 每周 1 次（哪怕 200 字） |

### 志 / 资源（方向/结构）

| 保底 | 最低剂量 |
|---|---|
| 记账 | 每天 1 笔，或每周补一次 |
| 预算/目标检视 | 每周 15 分钟 |
| 目标行动 | 每周 1 次，推进 1 个目标 |

### 可选模块

穿搭、功法、冥想、社交、学习加量——**不是保底**。状态好再做，不做不算失败。

---

## 五、每天只回答三个问题

1. **今天哪个底最危险？**（睡眠/吃饭/情绪/专注/钱）
2. **今天只保哪 3 个底？**（不超过 3 个）
3. **其他模块怎么办？**（明确「暂停」，不扣分）

示例：

```
今天：黄
最危险：睡眠 6.2h
只保 3 个：睡够 7h / 1 顿蛋白 / 20min 走路
暂停：学习加量、社交、穿搭
```

这比 20 个模块都打一遍分更可执行。

## 六、周复盘：看「哪个底连续没保住」

每周 5 分钟，只问：

1. 哪个底**连续 3 次**没保住？
2. 是**能力、机会、动机**哪一环断了？
3. 下周只改**环境**，不加意志力。

| 没保住 | 可能原因 | 环境改法 |
|---|---|---|
| 睡眠 | 晚上刷手机/加班 | 23:00 路由器定时、睡前充电器放客厅 |
| 吃饭 | 没备餐/会议挤 | 周日备 2 份蛋白、下午会议不排饭点 |
| 训练 | 通勤/时间 | 训练包放门口、把训练排进日历 |
| 专注 | 消息打断 | 45 分钟飞行模式、关通知 |
| 记账 | 忘记 | 支付后立刻记、每周固定 15 分钟补 |
| 情绪 | 孤立/过载 | 每周固定一次联系、减一个承诺 |

**核心**：不是「下周更自律」，是「下周环境哪里不一样」。

## 七、模块如何映射

| 层 | 模块 | 角色 |
|---|---|---|
| 体 | 睡眠、饮食、饮水、运动、休息、吃药、功法 | 保底工具；训练是「提升容量」，不是保底本身 |
| 情 | 情绪、关系、独处、冥想、恢复 | 保底工具；关系是长期投资 |
| 智 | 学习、思考、输出、成长 | 专注块 + 周输出是保底；加量可选 |
| 志/资源 | 记账、预算、时间、目标、穿搭 | 记账/预算/目标检视是保底；穿搭可选 |
| 元 | 灯、今日状态、日程、回顾 | 决定今天保哪 3 个底 |

所有模块只回答一个问题：**它是保底工具，还是可选加量？**

## 八、产品落点

### 1. 今日卡

```
今天：黄
最危险：睡眠
保 3 个底：睡够 / 1 顿蛋白 / 20min 走路
[ 就按这个 ] [ 调整 ]
```

- 不显示 20 个模块分数；
- 不选中的模块显示「今天暂停，不算失败」。

### 2. 模块页

- 每个模块显示「保底 / 加量」标签；
- 只读今日状态，不互相写；
- 例：训练页显示「今天保底：20min 走路；加量：Push 训练（可选）」。

### 3. 周复盘

- 连续未保住的底；
- 能力/机会/动机分析；
- 一个环境改动。

### 4. 数据

```json
floors: {
  "date": "2026-10-24",
  "chosen": ["sleep", "protein", "walk"],
  "done": ["protein", "walk"],
  "risk": "sleep",
  "paused": ["study", "social", "wardrobe"]
}
```

独立 `lifeflow-floors-v1`；不做总分。

---

## 九、分阶段

- **P0**：今日卡 + 四域保底清单 + 每天选 3 个底；
- **P1**：训练/睡眠/学习/记账 4 页显示「保底/加量」；
- **P2**：周复盘「连续没保住 + 环境改法」；
- **P3**：趋势（只展示，不宣称因果）。

## 十、不做什么

- 不做 20 模块总分；
- 不做每日全模块打卡；
- 不用「自律」解释结构性问题；
- 不自动替用户做决定；
- 不把可选模块没做当成失败。
