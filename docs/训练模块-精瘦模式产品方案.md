# 训练模块 · 精瘦 / 薄肌模式（产品方案）

> 决策：把 **精瘦（薄肌）** 设为训练模块的默认目标，而不是把「增肌/力量」当默认。
> 训练结构沿用 v3：3 天全身 A/B/C + 2 天 Zone2 + 功能三项；改的是**默认值、指标、文案、进度页**。

---

## 一、目标定义（产品口径）

- 正式名：**精瘦**
- 用户语言：**薄肌**
- 解释：**体脂较低 + 肌肉量中等 + 线条清晰**，不是「小重量练薄」，也不是「只做有氧」。
- 不承诺：局部减脂、体重必降、几周出腹肌。

---

## 二、默认计划（Lean Template）

| 周一 | 周二 | 周三 | 周四 | 周五 | 周六 | 周日 |
|---|---|---|---|---|---|---|
| A 蹲主导 + 农夫行走 | Zone2 45′ | B 髋主导 + 爆发力 | Zone2 45′ | C 混合 + 负重旋转 + 面拉 | 快走 45′ | 休 |

- 力量 3 次，2–3 组/动作，6–12 次，RPE 7–8，每肌群 8–10 组/周；
- 有氧 **195 分钟/周**（2×45 Zone2 + 3×30–45 快走），日常步数 8–10k；
- 功能三项每周各 1 次；
- 周六不加弱项日，留给快走/休息。

---

## 三、今日页（Lean 优先）

```
训练                          ⚙︎
本周  力量 3/3 · 有氧 135/180 · 步数 7.2k/8k
┌──────────────────────────┐
│ 今天：A · 蹲主导          │
│ 深蹲 / 卧推 / 划船 · 55′  │
│ + 农夫行走 4×25m          │
│ [ 开始训练 ]  [记体重]    │
└──────────────────────────┘
```

- 首屏只强调三件事：**今天练什么、有氧够不够、体重/腰围趋势**；
- PR / 1RM 不进首屏，放进度页次级；
- 休息日显示「走路 30′ + 睡够」，不显示热身。

---

## 四、训练中（Lean 版）

- 力量：组行（重量/次数/RPE）、休息计时、上次成绩；
- 有氧：周二/周四 45′，记录实际分钟与 RPE；
- 功能三项：行走 kg×m、爆发 触地/高度、旋转 kg×次/侧；
- 结束总结：时长、有氧分钟、力量容量、完成组；PR 只做一行小字，不抢主视觉。

---

## 五、进度页（两段：训练 / 身体）

### 训练

- 力量 3/3、有氧 195/180、三项 3/3；
- 4 周依从率；
- 容量与 e1RM 放次级，用来确认「减脂期有没有掉力量」。

### 身体

- 体重：7 天平均 + 周变化 %；
- 腰围：每周一次；
- 步数：周均；
- 照片：可选，本地保存（V2）。

**不做的**：体脂秤同步、BMI 评判、每日称重焦虑。

---

## 六、安全护栏（Lean 模式核心）

| 信号 | 提示 |
|---|---|
| 体重下降 >1%/周 | 掉太快，热量缺口收小 100–200 kcal，保力量 |
| 连续 2 周体重不动 | 加 100–200 kcal 缺口，或每天多 2k 步 |
| e1RM 4 周下降 >10% | 检查蛋白/睡眠，考虑 refeed |
| 有氧 >300 分钟/周 + 力量 3 次 | 恢复风险，减有氧或加吃 |
| 连续 2 周睡眠 ≤2 分 | 减 1 组/动作，或提前减量 |

训练模块只做提示，不自动改计划。

---

## 七、数据模型新增

```json
profile: {
  goal: "lean",
  heightCm: 175,
  startWeightKg: 72,
  startWaistCm: 82
},
bodyMetrics: [
  { "date": "2026-10-24", "weightKg": 71.4, "waistCm": 81.5, "steps": 8200 }
]
```

Session 模型不变；体重/腰围/步数独立存，避免污染训练统计。

---

## 八、与饮食模块的边界

- 训练模块**不内嵌热量/蛋白计算**；
- 进度页只放一个入口：「去饮食模块看热量/蛋白」；
- 如果饮食模块还没准备好，先显示公式：蛋白 1.6–2.2 g/kg、缺口 300–500 kcal；
- 体重/腰围由用户每周手填一次，不做每日强制。

---

## 九、V1 范围

- 默认 goal = lean，加载 Lean Template；
- 今日页显示力量/有氧/步数进度；
- 训练中 + 总结；
- 进度页：训练 + 体重/腰围（手填）；
- 护栏提示（至少「掉太快」与「力量下降」两条）。

## 十、不做

- 不做增肌/力量模板的默认入口（以后可选）；
- 不做每日称重、体脂秤、HealthKit；
- 不做「局部减脂」动作推荐；
- 不做「小重量多次数塑形」文案。

---

## 十一、验收

- 首次打开默认「精瘦」，计划是 3+2+三项；
- 今日页能看到有氧 135/180，而不是只有力量；
- 纪录一次 50 分钟训练，账户只多 50 分钟；
- 进度页能填体重/腰围，并显示周变化；
- 体重掉 >1%/周时出现护栏提示。
