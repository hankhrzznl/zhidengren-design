# 训练模块 · 最终方案（PPL · 精瘦版）

> 2026-10-23 定稿。目标：精瘦 / 薄肌；健身房器械；PPL 3 练 1 休；低冲击有氧；3 周 build + 1 周 deload。
> 代码入口：`pages/v3/training.html` + `pages/core/training.js`。

---

## 一、4 天循环

| Day 1 Push | Day 2 Pull | Day 3 Legs | Day 4 Rest |
|---|---|---|---|
| 卧推 3×6–8 | 引体/下拉 3×6–10 | 深蹲 3×5–8 | 快走/单车 30–40′ |
| 上斜哑铃卧推 3×8–10 | 划船 3×6–10 | RDL 3×6–8 | 或完全休息 |
| 侧平举 2×12–15 | 面拉 2×15 | 腿举 2×8–10 | |
| 三头下压 2×10–12 | 弯举 2×10–12 | 提踵 2×12–15 | |
| + 爆发力（前） | + 负重旋转（后） | + 农夫行走（后） | |

- 不按周几，按固定起始日 + 4 天循环；
- 3 练 1 休 ≈ 5.25 次力量/周；每肌群每 4 天一次；
- 每次 45–55 分钟，RPE 7–8，留 1–3 次。

## 二、进阶

- 2–3 组/动作，6–12 次；
- 双重进阶：达次数上限且最后一组 RPE≤8 → 加 2.5–5kg（下肢）/1–2.5kg（上肢）；否则加 1 次；
- 一周只加一个变量；
- 不做到力竭；减脂期最后组 RPE 9 封顶。

## 三、功能三项

- 每月一个主项、两个辅项；三项每周都出现；
- Push 挂爆发力（力量前）、Pull 挂旋转（力量后）、Legs 挂行走（力量后）；
- 主项 4 组、辅项 3 组；下月轮换主项。

## 四、有氧

- Push 后单车 15–20′；Pull 后坡度走 15–20′；休息日 30–40′；
- 每周 150–180 分钟低冲击；每天 6–8k 步；
- 腿日不做有氧；不跑步、不 HIIT；划船第 4 周再加。

## 五、热身

按当天焦点：推（肩绕环/外旋/肩胛俯卧撑/轻卧推）、拉（猫牛/拉开/肩胛引体/轻划船）、腿（髋铰链/徒手深蹲/臀桥/腿摆）；正式组前空杆→40%→60%→80%。

## 六、减载

PPL 高频默认 **3 周 build + 1 周 deload**。

| 参数 | 正常 | A 双降 | B 保强度 |
|---|---|---|---|
| 频率 | 3 练 1 休 | 不变 | 不变 |
| 组数 | 2–3 | 1–2 | 1–2 |
| 重量 | 常规 | 70–85% | 85–90% |
| RPE | 7–8 | 5–6 | 6 |
| 三项 | 主 4/辅 3 | 各 2 | 各 2 |
| 时长 | 45–55′ | 30–40′ | 30–40′ |

- 减脂/关节/睡眠差选 A；只是容量疲劳选 B；
- 不换动作、不测试、不冲 PR；有氧不变或 −20%；
- 减脂期 3–5 天维持热量；结束后测试，下一周 90–100% 恢复。

## 七、吃与身体

- 减脂：维持 −300–500 kcal，蛋白 1.6–2.2 g/kg，−0.5–1% 体重/周；
- 已偏瘦：维持 ±100 kcal，看腰围/照片；
- 每周固定称重（7 天平均）、量腰围；连续 2 周无变化再调 100–200 kcal。

## 八、产品 M1

- 今日：4 天循环 + 今天卡 + 近 7 天统计 + 最近；
- 训练中：热身清单、力量组行（重量/次数/RPE）、三项、有氧、休息计时；
- 总结：真实时长、容量、组数、有氧分钟；
- 进度：本周小结（力量/有氧/时长/容量/连续周/本周 PR）、体重腰围、4 周容量、e1RM、PR 卡、旧记录只读、肌群组数；最近训练可删除并回滚分钟；
- 计划：4 天模板可编辑（动作库选择/组数/次数/肌群/三项/有氧）+ 本月主项 + 减载 A/B 模式 + 循环起点 + 手动本周减载 + 导出 JSON；
- 一次 session 只写一条 `运动` 分钟；旧记录只读 + 导出。
