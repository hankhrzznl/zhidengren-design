# 记账 · 每月 CSV 方案（当前正式方案）

> 适用：只用微信钱包 + 支付宝（余额宝 / 绑卡）付款，不刷卡、不用 Apple Pay、不打开银行 App 消费。
> 结论：**每月 1 号导入一次支付宝 + 微信账单 CSV**，平时现金/临时手动记；不需要 Supabase、快捷指令、银行短信。

---

## 一、为什么这样最适合

| 渠道 | 在你的场景里 |
|---|---|
| 微信钱包 | 账单 CSV 全覆盖 |
| 支付宝（余额宝/银行卡） | 账单 CSV 全覆盖，且带「收/付款方式」 |
| 银行 App | 只用来转账，不产生消费，不需要接 |
| 现金 | 手动记 / 粘贴 |

所以不用做实时自动化，**批量导入反而最准、最省事**。

---

## 二、一次性设置

### 1. 建账户

记账 → 新账户：

- 资产：微信钱包、支付宝余额、余额宝、每张银行卡；
- 信用：花呗、白条（有才建），填账单日/还款日。

### 2. 设每月提醒

记账 → 右上角「自动记账」→ 每月对账提醒：

- 默认 **1 号**，可改 1–28；
- 保存 → 点「**添加到日历**」下载 `.ics`，用 iPhone 日历打开（每月重复 + 当天提醒）。

---

## 三、每月 1 号（3 分钟）

1. **支付宝**：我的 → 账单 → 右上角「…」→ 开具交易流水证明 / 导出账单 → 选整月 → 邮箱 → 解压 CSV；
2. **微信**：我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单 → 用于个人对账 → 选整月 → 邮箱 → 解压 CSV；
3. 记账 → **导入账单** → 选 CSV → 看预览 → 导入；
4. 回自动记账页点「**本月已完成**」。

导入会按「日期 + 金额 + 商户」去重，重复导入不会多记。

---

## 四、默认跳过「账户间挪钱」

导入页有一个默认勾选的开关：

> 跳过转账 / 充值 / 提现 / 还款

原因：

- 微信「零钱充值 / 提现」；
- 支付宝「余额宝转入 / 转出」「余额提现」；
- 信用卡 / 花呗还款；
- 银行卡之间转账。

这些不是消费，导入会把它们记成收入/支出，造成重复。默认跳过；如果你确实想记（比如核对余额），可以在导入页手动取消勾选。

---

## 五、平时

- 现金、临时、报销：记账页直接记；
- 复制了账单文本：点金额框右边「**粘贴账单**」，自动填金额/商户/分类，确认后记下。

---

## 六、不再使用

- Supabase 云收件箱（项目已删除，App 端配置为空）；
- iOS 快捷指令（银行短信 / Apple Pay）；
- 银行短信自动化。

代码保留但不再使用，不影响日常记账。

---

## 七、验收

- 导入页：默认「可导入 N 笔 · 跳过转账/充值 M 笔」；
- 关掉开关后能导入转账行；
- 每月提醒能保存、能生成 `.ics`；
- 记账页出现「每月对账」卡，点「本月已完成」后本月不再提示。
