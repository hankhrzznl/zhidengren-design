# 自动记账 · 全渠道落地方案

> 一张表看清：银行短信 / Apple Pay / 微信 / 支付宝 / 现金，各自能做到什么程度、怎么配。

## 一、四渠道总览

| 渠道 | 自动化 | 触发方式 | 落到哪 |
|---|---|---|---|
| **银行消费短信** | ✅ 全自动 | 快捷指令「信息」自动化 → POST 云收件箱 | Supabase `inbox` |
| **Apple Pay** | ✅ 全自动（iOS 17+） | 快捷指令「交易」自动化 → POST | Supabase `inbox` |
| **微信 / 支付宝（绑卡）** | ✅ 全自动 | 银行短信会照发 → 同第一条 | Supabase `inbox` |
| **微信 / 支付宝（零钱）** | ⚠️ 两步 | 截图 OCR / 复制账单 / 每月 CSV | 云收件箱或本地导入 |
| **现金 / 临时** | ⚠️ 两步 | Siri「记一笔」/ 背面轻点 / 手动 | 记账页 URL 或直接记 |

关键点：**微信/支付宝本身没有接口**，但「绑卡付款」会触发银行短信，所以大部分微信/支付宝消费可以被银行短信自动化覆盖；只有零钱余额付款需要 OCR 或 CSV 补。

## 二、统一入口

所有自动写入都走同一个接口：

```
POST https://<project>.supabase.co/functions/v1/inbox?token=<INBOX_TOKEN>
{
  "amount": 38.5,
  "type": "expense",
  "cat": "餐饮",
  "note": "午饭",
  "account": "微信钱包",
  "date": "2026-10-20",
  "source": "sms" | "applepay" | "share" | "manual"
}
```

App 打开时 `LightInbox.pull()` 拉取：

- 按 `cloudId` 去重；
- **跨来源去重**：同日期 + 同金额 + 5 分钟内、来源不同 → 只记一次（解决银行短信 + Apple Pay 重复）；
- 账户名找不到时回退第一个资产账户；
- 没有账户时跳过但不标记，补账户后能补记。

部署见 `docs/自动记账-Supabase收件箱.md`。

## 三、各渠道配置

### 1. 银行短信（全自动）

快捷指令 → 自动化 → 信息 → 包含「消费」→ 立即运行：

1. 「匹配文本」取金额：`(?:消费|支出|扣款)[^0-9]{0,6}([0-9]+(?:\.[0-9]{1,2})?)`
2. 「获取 URL 内容」→ POST 上面接口；
3. JSON 里 `source` 填 `sms`、`account` 填银行账户名。

### 2. Apple Pay（全自动）

自动化 → **交易** → 运行：

1. 取交易金额；
2. POST，`source: "applepay"`、`account: "微信钱包"`（或你实际扣款账户）。

> 只覆盖 Apple Pay；部分系统版本「交易」自动化不稳定，需要实测。

### 3. 微信 / 支付宝（绑卡）

不用额外配：银行短信已经覆盖。App 拉取后会按「日期+金额+来源」与 Apple Pay 去重。

### 4. 微信 / 支付宝（零钱）

**A. 截图 OCR（推荐，2 步）**

快捷指令「记一笔」接收**图像**：

1. 「从图像提取文本」；
2. 「匹配文本」`(?:¥|￥)\s*([0-9]+(?:\.[0-9]{1,2})?)`；
3. POST，`source: "share"`。

付款完成 → 截图 → 分享 → 记一笔。

**B. 每月 CSV（补全）**

支付宝/微信导出账单 CSV → 记账页「导入账单」：

- 自动识别支付宝/微信格式；
- 按「日期+金额+商户」去重；
- 预览前 5 笔再导入；
- 文件位置：`v3/bill-import.html`（自动记账页有入口）。

### 5. 现金 / 临时

- Siri：「嘿 Siri，记一笔」→ 快捷指令「要求输入」金额 → 打开 URL 或 POST；
- 背面轻点：设置 → 辅助功能 → 触控 → 轻点背面 → 双击 → 「记一笔」；
- 或者直接打开记账页。

## 四、推荐组合

```
绑卡消费（含微信/支付宝绑卡） → 银行短信自动化（全自动）
Apple Pay                    → 交易自动化（全自动）
零钱消费                     → 截图 OCR（2 步）
每月对账                     → CSV 导入（补漏）
现金                         → Siri / 背面轻点
```

覆盖率：日常消费 **90%+ 无需手动输入金额**；剩下的是零钱小额和现金。

## 五、验证清单

1. 配好 Supabase → 自动记账页「立即拉取」成功；
2. 用快捷指令 POST 一条测试：`{"amount":0.01,"note":"测试","source":"sms"}`；
3. 打开记账页，应出现「云收件箱记了 1 笔」；
4. 再 POST 一条同金额、`source:"applepay"`、同一分钟 → 应被去重；
5. 导出 CSV → 导入账单 → 重复导入应提示跳过重复。

## 六、边界

- iOS 不能读微信/支付宝 App 内部账单，零钱付款无法「完全无感」；
- Supabase 只负责收件，不改变手机本地账本；多设备各自拉取，不做账本合并；
- 要做完整同步，需要账号体系 + 账本上云（下一阶段）。
